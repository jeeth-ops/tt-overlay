⬇️ Clipper Helper (install once on this PC)

Checking…
Clips (newest first) — ⏳ wait → ✂️ cutting locally → 💾 saved locally → R2 → Drive → website. No internet? The clip is still cut and saved; it syncs by itself when the connection is back.
A tiny program that runs alongside vMix on this same PC. Set up once with a couple of clicks (no file editing) — after that, one click on "Start Recording" above starts vMix's own recording too, cuts FOUR/SIX/WICKET clips, and uploads them to Drive automatically.
Unzip it anywhere on this PC — includes ClipperHelper.exe, ffmpeg.exe and config.json.
📋 Setup instructions (click to expand) — one-time only
🔧 First time only (~2 minutes, no file editing):
  1. Right-click the downloaded zip → Extract All → choose any folder (e.g. Desktop). Keep ClipperHelper.exe, ffmpeg.exe and config.json together in that same folder.
  2. In vMix: click Settings → Web Controller and tick Enable Web Controller (keep the default port, 8088).
  3. Double-click ClipperHelper.exe. A black window opens (Clipper Helper running at http://localhost:5005) and, the first time, a Setup page automatically opens in your browser.
  4. On that Setup page, fill in the vMix recording file path and your website URL, then click 💾 Save.
  5. Keep that black window open for the whole match (minimize it, don't close it). You'll need to double-click ClipperHelper.exe again next match day.
🏏 Every match day (just 2 clicks):
  1. In this panel, click 🔗 Connect Google Drive, sign in with your Google account, and choose the folder where clips should be saved (only needed again if the session expired).
  2. Click 🔴 Start Recording above — this alone now starts vMix's recording too. That's it.
  3. Clips are cut and uploaded automatically whenever you press FOUR / SIX / WICKET. Click ⏹ Stop Recording when the match ends — this stops vMix's recording too.
Setup page is always reachable again at http://localhost:5005/setup if you ever need to change the folder or re-test the vMix connection.
If clips stop uploading mid-match, just click "Connect Google Drive" again — takes 2 seconds.
