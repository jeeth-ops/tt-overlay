⬇️ Clipper Helper (install once on this PC)

A tiny program that runs alongside vMix on this same PC. It's what actually cuts the FOUR/SIX/WICKET clips and uploads them to your Drive folder — no Chrome screen-share needed. One-time setup.
Unzip it anywhere on this PC — includes ClipperHelper.exe, config.json and setup steps.
📋 Setup instructions (click to expand)
🔧 First time only (do this once on this PC):
  1. Right-click the downloaded zip → Extract All → choose any folder (e.g. Desktop).
  2. In vMix: click Settings → Recording, then Browse next to Filename and pick one fixed file to always record into (e.g. D:\Recording\recording.mp4). Click OK.
  3. Inside the unzipped folder, right-click config.json → Open with → Notepad.
  4. Find the line with vmixRecordingFile and replace the path in quotes with the exact same file path you picked in vMix. Every single \ must be typed twice, like \\.
  5. Press Ctrl+S to save, then close Notepad.
🏏 Every match day:
  1. Open that unzipped folder and double-click ClipperHelper.exe. A black window opens — leave it open, don't close it.
  2. In this panel, click 🔗 Connect Google Drive, sign in with your Google account, and choose the folder where clips should be saved.
  3. Start recording in vMix, then click 🔴 Start Recording here in the panel.
  4. That's it — clips are cut and uploaded automatically whenever you press FOUR / SIX / WICKET.
If clips stop uploading mid-match, just click "Connect Google Drive" again — takes 2 seconds.
