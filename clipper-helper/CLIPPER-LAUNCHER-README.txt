ALLSPORTSLIVE CLIPPER LAUNCHER - kaise use karein
================================================

Isse Clipper panel ke button se chalu/band hota hai.
Koi kaali (cmd) window nahi dikhti, taskbar me bhi kuch nahi.

EK BAAR (har laptop pe sirf pehli baar):
 1. Ye saari files us folder me daalo jahan ClipperHelper.exe hai
    (ClipperHelper.exe, ffmpeg.exe, config.json ke bagal me).
 2. install-clipper-launcher.bat pe double-click karo.
    "DONE" likha aaye to window band kar do.

HAR MATCH:
 1. Panel me "Start Clipper" dabao.
 2. Pehli baar Chrome poochega program kholna hai kya:
    "Always allow" tick karo aur Open dabao.
 3. Clipper ka tab (Setup page) apne aap khul jayega, panel pe hara dot aayega.
    Pehli baar us tab me:
      - vMix Recording ka path daalo (jaise D:\ClipperRecording\recording.mp4)
      - Website URL (panel ka link) panel khud bhar deta hai - check kar lo
      - Save dabao. Agli baar se kuch bharna nahi padega.
 4. Match ke baad panel me "Stop" dabao.

KUCH GADBAD HO TO:
 - clipper-log.txt kholo (isi folder me) - Clipper ne jo bhi likha, sab wahan hai.
 - Folder badla? install-clipper-launcher.bat dobara chalao.
 - Hatana ho to uninstall-clipper-launcher.bat chalao.
